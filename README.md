# Giga Pet JavaScript Project

## Description

This project is a simple interactive Giga Pet game built using HTML, CSS, JavaScript, and jQuery. The user can take care of a virtual pet by clicking different action buttons that affect the pet’s stats.

## Features
Pet has properties: name, weight, and happiness
Buttons for:
Treat → increases happiness and weight
Play → increases happiness, decreases weight
Exercise → decreases happiness and weight
Nap → increases happiness
Prevents stats from going below zero using conditionals
Displays live updates of pet stats on the page
Shows pet comments after each action (no alerts used)
Extra Features (Above and Beyond)
Mood indicator based on happiness level (Happy, Okay, Sad)
Color-changing text based on happiness
Animations when interacting with the pet

## jQuery Methods Used
.fadeOut() and .fadeIn()
→ Used to smoothly update the pet’s comment text
.animate()
→ Used to create a bounce animation for the pet image
.css()
→ Used to dynamically change text color based on mood
